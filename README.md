### House Price Prediction Using Linear Regression

Developed a Machine Learning model to predict house prices based on key housing features such as area, number of bedrooms, and number of bathrooms. Performed data preprocessing, feature selection, and model training using the Linear Regression algorithm. Evaluated model performance using Mean Absolute Error (MAE), Mean Squared Error (MSE), and R² Score to measure prediction accuracy. Utilized Python, Pandas, and Scikit-Learn for data analysis, model development, and predictive analytics. This project demonstrates the application of supervised learning techniques for real-world price prediction problems.

**Skills:** Python, Machine Learning, Linear Regression, Pandas, NumPy, Scikit-Learn, Data Analysis, Data Preprocessing, Predictive Modeling.
